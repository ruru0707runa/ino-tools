# Social Publishing Reel Frame Check

## Check the sample frame against reference reels

- Render one complete sample reel before you build the rest of a batch, and pull still frames from the start, the middle and the end of the sample.

- Open each frame beside a reference reel frame the user approved, and compare how much of the frame is filled, how large the blank areas are, and whether the subject reads at a glance.

- Treat a frame with a large empty band, a small subject, or missing topic icons as a failed sample even when every line of text sits inside the safe zone.

- Fix the layout in the sample and show the revised frame to the user before you generate or schedule the remaining reels in the batch.

## Check density, icons and safe zones together

- Check that the title, the telop card and the character window fill the frame without crowding, and that no text sits where the phone microphone or interface can hide it.

- Check that each topic icon the brief names appears in the frame and is large enough to recognise at phone size.

- Read the telop at phone size against the narration timing, and shorten or enlarge it when it cannot be read in the time it stays on screen.

## Available connectors

- [Instagram](/opt/hatch/connectors/instagram/CONNECTOR.md) for scheduling the reels once the sample frame passes.

- [Threads](/opt/hatch/connectors/threads/CONNECTOR.md) for posting the same reels to Threads once the sample frame passes.

- Use `muse.connector_search` to find other connectors and `muse.skill_search` to find related skills.

- If nothing here fits, look on the web for a maintained API or MCP server and set it up with [Custom Connectors and MCPs](/opt/muse/skills/custom-connector-setup/SKILL.md), or build a custom connector.

## Alternatives for better results

- Reuse the approved sample layout as the template for the whole batch, and change one element at a time when a later reel underperforms.

- Keep the reference frames the user approved beside the brief, so a later batch is judged against the same standard.
